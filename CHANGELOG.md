# Changelog

## 0.1.0 - Beta

- One shared `augelab` skill for Codex and Claude Code.
- Connect to an existing AugeLab Studio MCP server over local HTTP.
- Separate marketplace and plugin manifests for each client.
- Connection recovery guidance uses Studio's displayed active port.
- Reproducible ZIP packages, SHA-256 checksums, and package validation in CI.

Codex local installation has been verified. Claude Code runtime and live Studio
workflows have not yet been verified. This beta is not listed in the OpenAI or
Anthropic public directories.
